## Third-Party Assets & Dependencies

To comply with the Unity Asset Store EULA, paid third-party packages are excluded from this repository. If you wish to open and build the project locally in Unity, you will need to import the following asset manually:

* **Text Decal: Dynamic, Surface-Aligned & Shaded** – Available on the [Unity Asset Store](https://assetstore.unity.com/packages/tools/level-design/text-decal-dynamic-surface-aligned-shaded-302653?srsltid=AYCX9vJQ_uzWuQcB1FjfNtwyUQMEtmYux7XRooPFng2BCHGwojr1ygRI).
